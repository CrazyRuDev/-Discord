# Поиск сообщений в Discord и сохранение в файл

Скрипт для Discord Web, который помогает собирать результаты поиска сообщений по страницам и сохранять их в один документ.

## Что делает скрипт

Скрипт работает поверх Discord Web и добавляет небольшую панель управления. С её помощью можно:

- запускать сбор найденных сообщений;
- останавливать сбор в любой момент;
- задавать лимит страниц для обработки;
- задавать задержку между страницами;
- сохранять собранные результаты;
- копировать итоговый текст;
- экспортировать данные в TXT и JSON.

## Для чего это нужно

Этот скрипт нужен в тех случаях, когда в Discord найдено много сообщений одного пользователя, и их нужно не просматривать вручную по страницам, а собрать в один документ для дальнейшего анализа, чтения или сохранения.

## Основные возможности

- поиск сообщений через стандартный поиск Discord Web;
- постраничный сбор результатов;
- остановка процесса кнопкой;
- сохранение промежуточного прогресса;
- экспорт в текстовый файл;
- экспорт в JSON;
- перемещаемая панель управления на странице.

## Как использовать

1. Установите Tampermonkey в браузер.
2. Создайте новый userscript.
3. Вставьте код скрипта.
4. Сохраните его.
5. Откройте Discord Web.
6. Выполните поиск сообщений нужного пользователя.
7. Запустите сбор через панель скрипта.
8. После завершения сохраните результат в TXT или JSON.

## Что важно учитывать

Скрипт зависит от текущего интерфейса Discord Web. Если Discord изменит разметку страницы или способ отображения результатов поиска, отдельные части скрипта могут потребовать доработки.

## Формат результата

Собранные сообщения можно сохранять в один документ. В итоговом тексте каждая запись должна содержать:

- дату и время сообщения;
- имя автора;
- текст сообщения.

При необходимости формат можно доработать отдельно.
